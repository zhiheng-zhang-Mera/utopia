# 城市名称、入网名称与启动前检查

DATE: 2026-10-04
PAIR_STATUS: SYNCHRONIZED

城市名称由本机数据库持久保存，首次默认为主机名称；在设置页修改“城市名称”后，配对标题、城市快照、发现描述及页面名称同步更新。城市名称是显示信息，城市身份仍由 cityId 确定，改名不新建城市。城市成员使用目标城市的实际名称，不把自己的主机名当成目标城市名。

发起入网申请时，先填写此设备的入网名称。取消不提交申请；名称通过源切换携带到目标城市，显示在审批卡和已连接的 Web 控制面。名称仅作显示，不授予信任。

启动器先检查固定主机协调端口，再检查旧版 Gateway 进程及其监听端口。发现一座现存城市时复用，不因请求不同端口而新增。发现多个进程，或已监听但身份探测失败时，阻止启动并提示已有端点。旧版相对路径启动且无法定位本地凭据时，打开已有城市的配对页，不创建另一座城市。

新版 Gateway 生产入口也执行同样检查。未升级的旧启动器不会因此自动获得新逻辑，应更新实际启动的安装目录。检查只针对本机 Gateway，不会结束其他设备的城市，也不删除历史城市数据库。发现列表中同名城市必须根据 cityId 与地址区分；名称相同不证明同一城市。
