# Dormant Worker Pool and headless agent seam

The Gateway registers `worker-pool` dormant without any adapter, network connection, credentials or timer. STANDARD_DEVICES remains the sole default active profile. Explicit test construction can wrap the existing canonical backend with a pool-member allowlist and validated City node descriptors. Dispatch/claim/report/control delegate to canonical state; control also checks canonical task ownership. This does not activate a product Worker Pool profile, rewrite Windows bootstrap or add a queue.

`createHeadlessAgent` takes a versioned identity/role/capability/resource registration, an injected existing authenticated Gateway request adapter, and opaque node/control credential handles. Construction performs no I/O. The caller explicitly invokes register, heartbeat, runOne, drain, resume, cancel or stop. Heartbeat returns the City's canonical descriptor. CPU/memory/disk reports reuse existing telemetry; unreported resources remain unknown. GPU-specific canonical advertisement is not implemented by this telemetry adapter.

Only an authorized own-device control handle can pause sharing for drain; denial remains a denial. Drain prevents new work canonically while held work can finish. Explicit resume restores sharing paused by this agent; restart does not automatically undo an owner's pause. Cancel uses the existing authorized task cancellation route, task/epoch fences, an in-flight control guard and a cooperative AbortSignal. A process/executor ignoring cancellation cannot be forcibly preempted by this JavaScript seam. Stop during an unresolved claim returns AGENT_BUSY and leaves it intact; retry after resolution. Transport operations time out; uncertain effects are never automatically replayed.

Restart uses existing node re-registration semantics: interrupted canonical work becomes FAILED and is not executed twice. `resume()` resumes admission after drain, not checkpoint execution. Checkpoint-authorized continuation, real Workbench deployment, HA, Linux/macOS device validation and primary-agent migration are not claimed.
