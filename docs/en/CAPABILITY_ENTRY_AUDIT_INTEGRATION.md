The portable current audit requires `CEX790_REGISTRY_ROOT` pointing to a Digital-City checkout; run `node scripts/cex790-inventory.mjs` after installing root and City dependencies. It writes `evidence/raw/mission-book/CEX-790/current/capability-inventory.json`, with exact source identity, input hashes and Registry state. Its classes are discovery candidates. See `evidence/raw/mission-book/CEX-790/current/RECONCILIATION.md` for the independent catalog reconstruction, all classified differences, residual owning-programme debts and failed/passing probes.

An unusable theme or experiment store degrades its capability rather than stopping the City. Health exposes artifact storage state.
