# Artifact and checkpoint component evidence

Stage B local scope extends the existing authorized filesystem adapter. Pins and leases persist in its index; eviction skips protected entries. Revocation records DELETE_PENDING before removing bytes and records DELETE_FAILED on failure. Reads reject revoked entries. Opaque transfer IDs retain partial files across adapter restart; append checks offset, digest and source version. Only complete verified bytes enter the readable artifact index. Orphan blobs fail quota admission closed; stale writer locks require operator recovery rather than unsafe automatic removal.

repositorySnapshotManifest records an explicit repository commit and selected dirty-file digests, rejecting traversal and common credential filenames. It performs no repository copying or pull. Arbitrarily named files can still contain secrets: the caller must select approved content.

restoreCheckpoint keeps same-attempt compatibility and allows an explicitly approved new attempt with sourceAttemptId and targetFence. Saved source binding remains immutable. Provider/input/task/stage and supplied executor/runtime/model/platform/dependency fields must match; side effects must be NONE and committed results are refused. The caller owns authoritative fence and approval validation; this helper does not issue a fence or replace checkpoint-gate.

Local tests use real temporary files and a chunked integer CPU sum: restoring cursor 500 produces the same final digest as an uninterrupted 1000-step computation. Evidence: .runtime/pcf-stageb-artifacts-{red,manifest-red,green}.log. This is local component evidence, not physical acceptance. Dual-host network transfer, two real worker environments, integration/UI, disk-full injection, cleanup-failure injection, terminal CI and cross-host review remain NOT_RUN.

## Review repairs

Authorized cancelTransfer and cleanupExpiredTransfers release partial-byte/item quota; failure retains a cancelled DELETE_FAILED journal for visible authorized retry. transferStatus exposes journal state. Expiry cleanup requires DELETE authorization, does not infer permission from expiry, and skips published artifacts. Revoked transfers require explicit authorized cancellation. Durable PUBLISHING journals cover the rename-to-index gap: retry verifies bytes/digest and publishes exactly one reference. Descriptor cleanup failure returns the published reference and records PUBLISHED_CLEANUP_FAILED; retry cleans it without double-counting quota. Unknown orphan blobs still fail closed. storageIo overrides are an explicit trusted adapter seam used for injected ENOSPC/EACCES failures; these tests do not demonstrate a physically full disk.

New-attempt checkpoint recovery now refuses missing executor/runtime/model/platform/dependency bindings. modelVersion NOT_APPLICABLE_CPU is allowed only with workloadKind CPU. approval.validateFence(targetBinding, {sourceBinding,artifact,targetFence}) is mandatory and must check the canonical source allowance and target attempt/epoch/holder. The helper issues no fence. An authorized persistent restoration claim permits one state release for a target task/attempt; repeated restoration refuses CHECKPOINT_RESTORE_ALREADY_CLAIMED, including after adapter restart. Final result submission and fence validity remain canonical-owner responsibilities. Legacy same-attempt restores with absent compatibility remain supported and are explicitly weaker, never evidence for validated new-attempt recovery.
