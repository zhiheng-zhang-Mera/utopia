# Product V0

Android Compose and browser control surfaces operate the same durable city state through a platform-neutral protocol. The reference node executes fixed safe tasks with real file I/O. The physical-device acceptance includes shared task/result/events, Gateway restart and Wi-Fi interruption/recovery.

The exact tested implementation and APK hash are recorded in [acceptance](../../evidence/en/ACCEPTANCE_V0.md). The published debug APK is the installed physical-device build; CI independently builds the same Android sources with its own debug signing key. Those APK bytes may differ. Source lives on main; working implementation history is retained on codex/product-v0.

[GitHub checks](https://github.com/zhiheng-zhang-Mera/utopia/actions/workflows/ci.yml) run Windows gateway/Web tests, bilingual pairing, Android unit tests and APK build. [Release download](https://github.com/zhiheng-zhang-Mera/utopia/releases/tag/v0.1.0-product) contains the physical-device APK. Runtime databases and pairing tokens are not distributed.

Start using the host and Android runbooks. This release is a LAN, foreground reference product with one trusted runtime node. Follow-up scope remains POST_V0.
