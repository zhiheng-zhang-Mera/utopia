# Device recovery / 设备恢复

Open Settings on the City's owner Web connection. Clone findings show typed reasons without credential fingerprints. An unbound installation has an explicit logical-device selector and owner confirmation: choose the original device, confirm, then Recover. No device is selected or deleted automatically. Revocation is explicit. Members see their own installation and owner guidance; server authorization remains authoritative. Credential changes clear earlier selections and confirmations.

在城市所有者的 Web 连接中打开设置。身份冲突显示类型原因，不显示凭据指纹。未绑定安装必须由用户选择原有设备并明确确认后恢复；不会自动选择或删除设备。撤销也需要明确操作。成员仅看到自己的安装和所有者处理指引，权限仍由服务器决定。切换凭据后旧选择与确认会清除。

Android: UTOPIA header More (更多) → Settings (设置) → Device recovery (设备恢复). Refresh installation state, inspect folded identity details, or open owner Web Settings. The browser link contains no credential and requires the owner to authenticate normally. After owner approval, return to Find City / reconnect. A connection failure provides explicit guidance rather than reporting recovery success.

Android：顶部更多→设置→设备恢复，可刷新安装状态、展开身份详情、打开所有者 Web 设置。链接不携带凭据，所有者仍须正常认证。批准后返回寻找城市并重新连接。无法连接时显示提示，不宣称恢复成功。
