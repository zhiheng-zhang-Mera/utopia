# Capability catalog / 能力目录

Web: View all capabilities next to the Ask bar → View all capabilities on Ask/Do. Android: Ask → 查看全部能力. Both fetch the existing GET /api/v0/ask/targets contract. Disabled targets show the backend reason; lists have no separate hard-coded target inventory.

Choose a target to prepare its example and exact backend selection, then edit or submit. Selection alone does not execute. Changing the prepared text returns to normal Ask routing. Side effects still use the existing confirmation step.

Web：Ask栏旁“查看全部能力”→Ask/Do目录按钮。Android：Ask→查看全部能力。两端使用后端真实目录。不可用目标禁用并显示原因，不维护第二份固定清单。选择只准备示例和目标，提交才进入原有Ask流程；有副作用时仍须确认。
