# City 多主机成员、通信和本机角色切换

DATE: 2026-10-04
PAIR_STATUS: SYNCHRONIZED

每台主机首次启动默认是自己的城市主机，代理使用本机稳定身份与名称。加入其他城市成功后，本机保存入网名称及安装身份，只停止本机原 Gateway、Rooms 和原代理，保留原城市数据库，启动目标 City 的成员代理。目标主城不停止。成员角色独立持久保存；重启继续接入原目标，凭据缺失或目标无法访问时不自动恢复另一座主城。

设备列表将城市主机、已入网成员、计算节点及 Web 控制端统一展示，当前设备“本机”置顶，其他设备使用入网名称。重复标签不增加同一设备条目；名字相同不合并不同身份。只有本机且持有本机所有者凭据的请求可以发起角色切换，成员不能降级目标主城。

点击设备可发送消息；City 记录消息并中转，接收设备确认后标记已接收。成员只能读取自己发送或接收的消息。仅服务器收到消息不代表设备已接收。

安装版计算代理连接后共享现有安全任务能力，显示真实 CPU、内存和磁盘遥测；设备详情可停止或开启本机资源共享，任务可严格指定目标设备。停止共享阻止继续领取，不中止已执行中的任务。纯 Web 接入只提供控制/通信，未连接代理时不宣称提供硬件。GPU、任意命令和模型服务不是此版本的已验证能力。

加入失败或本机存在未完成任务时保留主城状态。新入网不能选择已有设备身份；本机代理的心跳、领取与结果提交受成员身份限制。浏览器只持有可续期会话，持久安装密钥留在本机文件；HTTP 和 relay 入网使用同一身份逻辑。

双物理主机实测缺失时保持 NOT_RUN；隔离多代理与浏览器测试不证明跨地区或硬件性能。
